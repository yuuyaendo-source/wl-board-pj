# 目的
Next.jsアプリ (`src/app`) 内に、Three.jsを使って3Dキャラクター(VRM)を表示するコンポーネントを作成したいです。
これにより、外部アプリを使わずにブラウザ上でアバターを表示させます。

# 指示

## 1. ライブラリのインストール
ターミナルで以下のコマンドを実行するよう指示、または実行してください。
`npm install three @types/three @react-three/fiber @react-three/drei @pixiv/three-vrm`

## 2. アバター表示コンポーネントの作成
`src/components/AvatarCanvas.tsx` (または .js) を新規作成し、以下の機能を実装してください。

- **Canvas設定:**
  - 背景は透明 (`alpha: true`, `gl={{ alpha: true }}`) にする。
  - カメラ位置を調整し、モデルのバストアップ（胸から上）が右下に映るようにする。
- **VRMモデルの読み込み:**
  - `@react-three/fiber` の `useLoader` と `three/examples/jsm/loaders/GLTFLoader` を使用。
  - ローダーに `@pixiv/three-vrm` の `VRMLoaderPlugin` を登録して `.vrm` ファイルをパース可能にする。
  - モデルのパスは `/avatar.vrm` (publicフォルダ直下) とする。
- **ライト設定:**
  - キャラクターが暗くならないよう、`ambientLight` と `directionalLight` を適切に配置する。
- **コンポーネント構成:**
  - `AvatarModel`: VRMを読み込んで表示する内部コンポーネント。
  - `AvatarCanvas`: Canvas全体をラップし、画面の「右下」に固定表示 (`position: fixed; bottom: 0; right: 0;`) するスタイルを適用したコンポーネント。z-indexは付箋より手前（または奥、指定可能に）にする。

## 3. 全体レイアウトへの配置
`src/app/layout.tsx` (または `page.tsx` の適切な場所) に `<AvatarCanvas />` を追加し、
どのページを開いても画面右下にアバターが常駐するようにしてください。

# 注意点
- Next.js の App Router (Server Components) を使用しているため、Three.js を使うコンポーネントにはファイルの先頭に `'use client';` を必ず付けてください。
- VRM読み込み時にエラーが出ないよう、非同期読み込みの `Suspense` でラップするなどの配慮をしてください。
