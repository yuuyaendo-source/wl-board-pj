# デプロイとマイグレーション手順

最新リビジョン（`n4o5p6q7r8s9_add_is_help_request_to_sticky_notes.py` まで）を本番環境に安全にデプロイし、マイグレーションを適用する手順です[cite: 1]。

---

## 前提

- 本番サーバー: `wlboardsys-app-01` (`172.16.1.203`)[cite: 1]
- プロジェクト配置: `/var/www/wlinko-pj`[cite: 1]
- バックエンドコンテナ: `linko-backend-blue` または `linko-backend-green`[cite: 1]

---


```bash

```

---

## Step 3: Blue/Green デプロイスクリプトの実行

`deploy.sh` を実行すると、自動的に新コンテナのビルド、ヘルスチェック、Alembic マイグレーション (`alembic upgrade head`)、チームシード (`seed_teams.py`)、静的アセットのホスト同期 (`shared_static/frontend`)、Nginx 切り替え、旧コンテナの停止が行われます[cite: 1]。

```bash
cd /var/www/wlinko-pj/board-system/deploy
./deploy.sh
```

---

## Step 4: 手動でマイグレーションのみ実行したい場合（任意）

特定コンテナに対して直接マイグレーションを実行したい場合は、以下を実行します[cite: 1]。

```bash
# 現在アクティブなバックエンドコンテナを指定して実行
docker exec -it linko-backend-blue alembic -c /app/alembic.ini upgrade head
```

- 成功時には `Running upgrade m3n4o5p6q7r8 -> n4o5p6q7r8s9, add is_help_request to sticky_notes` 等が出力されます[cite: 1]。
