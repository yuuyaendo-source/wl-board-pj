## 機能追加アイデア
- [x] ランダムに配置している付箋が画面内にゆっくり回遊するように動く
- [x] 付箋は一定時間でフェードアウトする
- [x] １つの付箋の表示時間は7秒にする
- [x] 全ての付箋を周回する
- [x] ランダムに表示されている付箋をマウスまたはタッチ操作で動かせるようにする
- [x] 気になった付箋を固定エリアにピン留めできる
- [x] ピン留めエリアで付箋と付箋をぶつけることができ、ぶつけられた付箋の内容からAIによる新しいアイデアの端的な付箋が生成される
- [x] 付箋の生成時はフェードインするように表示される
- [x] 生成された付箋は付箋ボード、BoardSystemに反映される
- [x] AIによって生成されたアイデア付箋について壁打ちができる

### 壁打ちUI（提案・実装内容）
- **操作**: AI生成付箋（緑系で表示された付箋）を**クリック**すると「壁打ち」パネルが開く。
- **パネル内容**:
  - 選択した付箋のテキスト表示
  - 任意入力欄「質問や掘り下げたいこと」（例: このアイデアを実現するには？）
  - 送信ボタン → リン子が2〜3文で返答
  - 返答はパネル内に表示（音声は従来のAIコメントと同様に必要なら拡張可能）。
- **閉じる**: パネル右上の × で閉じる。ドラッグした付箋ではクリックでパネルは開かない（誤操作防止）。
