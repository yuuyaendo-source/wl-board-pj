## アプリ設計書：次世代オフィス空間「AI-Board（仮）」
### 概要（コンセプト）
「誰の」・「どんな課題を」・「どう解決する」アプリですか？
#### ターゲット：
情報感度を高めたい自社社員（および、オフィス回帰・活性化に悩むクライアント企業の総務・情シス担当者）

#### 現状の課題：
ハイブリッドワークで「リアル」と「リモート」の会話が分断されている。
アナログ付箋は直感的だが、デジタル化（撮影・共有）が面倒で誰もやらない。
「勉強しろ」と言われると反発するが、楽しそうなことには興味を持つ。

#### 解決策（提供価値）：
「空間OS」：オフィスの壁自体を巨大なタッチパネル化し、アナログとデジタルを融合させる。
「ゼロ・フリクション」：定点カメラが常時監視し、壁に貼るだけで勝手にデジタル化される。
「AIファシリテーター」：AI Vtuberが常駐し、会議の賑やかしや情報へのツッコミを入れる。
必要な機能（ロジック）

#### AI（Antigravity）への指示書です。以下の仕様でコードを生成してください。
入力インターフェース
[ ] 定点カメラ (Logicool CC4900E)：4K映像を常時取得する（Python/OpenCV）。
[ ] マイク (YAMAHA)：会議室の音声を拾う。
[ ] Webアプリ：PC/スマホからテキスト付箋を投稿できる（既存アプリ改修）。
[ ] 赤外線タッチフレーム：壁面のプロジェクション画面をタッチ操作できる。

処理のルール（システムの中枢）
A. 付箋の自動デジタル化（エッジ処理）
[ ] カメラ映像から「黄色い四角形（付箋）」を検知したら、画像をトリミングする。
[ ] トリミングした画像はローカルに保存し、Webアプリのキャンバス上の「同じ位置」に即座に表示する。
[ ] セキュリティ制約：カメラの生映像はクラウドに送信せず、処理後のテキスト/画像データのみを扱う。
B. AI Vtuber連携（人格の統一）
[ ] トリガー：新しい付箋が貼られた時、または音声で話しかけられた時。
[ ] 思考：Gemini 3 API を使用し、キャラクター（例：毒舌だが親切な先輩）設定で応答を生成する。
[ ] 発話：生成されたテキストを「VOICEVOX（Docker版）」へストリーミング送信し、遅延なく喋らせる。
[ ] 動作：VMagicMirror等のアバターソフトと連携し、音声に合わせてリップシンクさせる。
C. 3Dアバター生成（未来機能）
[ ] Webアプリ上で「手書きの落書き」がアップロードされたら、画像生成AI（Stable Diffusion）で清書する。
[ ] 清書された画像から、3D生成AI（TripoSR）を用いて3Dモデルを生成し、画面内に登場させる。
D. インフラ・セキュリティ（CATO連携）
[ ] アプリケーションはDockerコンテナ内で動作させる。
[ ] 外部通信はCATO Networks経由とし、許可されたAPI（Gemini/AWS）以外への通信を遮断する。

画面イメージ
オフィス自体を「巨大な端末」に見立てます
壁面全体（プロジェクション）：
既存の「自社付箋アプリ」をダークモード（黒背景）で表示。
黒背景にすることで、リアルな付箋を貼った場所に光が重ならず、視認性を確保する。
右下または隅：
AI Vtuberのウィンドウを常時表示（「ON AIR」ランプのような演出）。
操作感：
巨大なスマホを操作する感覚で、指でデジタル付箋を移動・整理できる。
