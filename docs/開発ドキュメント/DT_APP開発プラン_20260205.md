
## 目的
AIボード（Linkoシステム）のアバターを、個人のPCにアバターにも常駐させ、お知らせなどを行うことで、アイデア投稿などを促す。情報のインプット機会を増やす。将来的には社内Webツールと連携する。

## 機能
- [ ] 基本的にアプリを開くとAIボードのパーソナルモードが開く
- [ ] ポップアップメッセージでのお知らせ機能
- [ ] お知らせ機能は業務作業に邪魔にならないような場所に表示する 例：右下に透過型メッセージ
- [ ] AIボードと連携して、お知らせする 例：Postit_board側新しい付箋が貼られたらお知らせ
- [ ] お知らせからワンクリックで適切なURLへ飛べる
- [ ] 適切なタイミングでニュースをお知らせ
- [ ] 適切なタイミングで付箋投稿を促す
- [ ] エントランス側のAIボードが受付モードになった場合にお知らせ
- [ ]  アバターは表示/非表示ができる
- [ ] アバターは将来的には自律した動きで表示できることを想定
- [ ] 音声ON/OFF機能がある
