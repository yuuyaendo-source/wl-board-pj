
## 目的
AIボード（Linkoシステム）のアバターを、個人のPCにアバターにも常駐させ、お知らせなどを行うことで、アイデア投稿などを促す。情報のインプット機会を増やす。将来的には社内Webツールと連携する。

## 機能
- [x] 基本的にアプリを開くとAIボードのパーソナルモードが開く
- [x] ポップアップメッセージでのお知らせ機能（右下トースト）
- [x] お知らせ機能は業務作業に邪魔にならないような場所に表示する 例：右下に透過型メッセージ
- [ ] AIボードと連携して、お知らせする 例：Postit_board側新しい付箋が貼られたらお知らせ（API連携は今後）
- [x] お知らせからワンクリックで適切なURLへ飛べる（トレイ「最後のお知らせを開く」）
- [ ] 適切なタイミングでニュースをお知らせ
- [ ] 適切なタイミングで付箋投稿を促す
- [ ] エントランス側のAIボードが受付モードになった場合にお知らせ
- [x] アバターは表示/非表示ができる（メニュートグル・将来のアバターウィンドウ用）
- [ ] アバターは将来的には自律した動きで表示できることを想定
- [x] 音声ON/OFF機能がある（メニュートグル）
- [ ] AIボードとの双方向連携（状態取得・イベント受信）は今後実装
