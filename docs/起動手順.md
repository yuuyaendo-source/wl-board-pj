# 各システムの起動手順

プロジェクト `wlinko-pj` 内の主要システムと、その起動方法の一覧です。

---

## 一覧

| システム | ディレクトリ | ポート | 概要 |
| ---------- | ---------------- | -------- | ------ |
| **付箋ボード（旧）** | `02_1_sticky-note/src` | 3000 | Next.js + Express + Socket.IO。リアルタイム協調付箋ボード。 |
| **AI-Board** | `02_2_AI-Board` | 5000 | Flask。付箋画像OCR・Geminiコメント・VOICEVOX・OSC。 |
| **Board System バックエンド** | `board-system/backend` | 8000（または 8001） | FastAPI + SQLAlchemy。4ボード用 API。 |
| **Board System フロント** | `board-system/frontend` | 3000（単体） / 3001（付箋ボード併用時） | Next.js。Main / Task / Personal / Morning。 |

---

## 1. 付箋ボード（02_1_sticky-note）

リアルタイム付箋・グループ化・AI-Board 連携。Board System へのリンク付き。

### 初回セットアップ

```powershell
cd 02_1_sticky-note\src
npm install
# 必要なら .env を .env.example から作成
```

### 起動

```powershell
cd 02_1_sticky-note\src
npm run dev
```

- **URL**: <http://localhost:3000>  
- **ボード例**: <http://localhost:3000/board/wl>

---

## 2. AI-Board（02_2_AI-Board）

付箋検知・Gemini コメント・音声合成。付箋ボードと連携する場合は両方起動。

### 初回セットアップ

```powershell
cd 02_2_AI-Board
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
# .env を .env.example から作成し、GEMINI_API_KEY 等を設定
```

### 起動（Flask Web API）

```powershell
cd 02_2_AI-Board
.venv\Scripts\Activate.ps1
.\start_server.ps1
```

または

```powershell
cd 02_2_AI-Board
.venv\Scripts\Activate.ps1
cd src\webapp
python app.py
```

- **URL**: <http://localhost:5000>  

### 付箋検知（カメラ／RTSP）を使う場合

別ターミナルで付箋検知を起動。

```powershell
cd 02_2_AI-Board
.venv\Scripts\Activate.ps1
.\start_detector.ps1
```

## 3. Board System（Wonder Rinko）

4ボード（Main / Task / Personal / Morning）＋ FastAPI バックエンド。**バックエンドを先に起動すること。**

### 3.1 バックエンド

#### 初回セットアップ

```powershell
cd board-system\backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
# 任意: GEMINI_API_KEY を .env に設定（AI 自動仕分け用）
alembic upgrade head
```

#### 起動

```powershell
cd board-system\backend
.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --port 8000
```

- **API**: <http://localhost:8000>  
- **ヘルス**: <http://localhost:8000/health>  

**ポート 8000 が使用中の場合**

```powershell
uvicorn app.main:app --reload --port 8001
```

その場合、フロントの `.env.local` に `NEXT_PUBLIC_API_URL=http://localhost:8001` を設定する。

### 3.2 フロントエンド

#### 初回セットアップ

```powershell
cd board-system\frontend
npm install
cp .env.local.example .env.local
# 必要なら NEXT_PUBLIC_API_URL を編集（バックエンドが 8001 のとき）
```

#### 起動（Board System のみ使う場合）

```powershell
cd board-system\frontend
npm run dev
```

- **URL**: <http://localhost:3000>  
- トップで「API 接続済み」と出ればバックエンド接続OK。

#### 起動（付箋ボードと併用する場合）

付箋ボードが 3000 を使うため、フロントは 3001 で起動。

```powershell
cd board-system\frontend
npm run dev -- -p 3001
```

- **URL**: <http://localhost:3001>  
- 付箋ボード側の `.env` に `NEXT_PUBLIC_BOARD_SYSTEM_URL=http://localhost:3001`  
- board-system の `.env.local` に `NEXT_PUBLIC_LEGACY_BOARD_URL=http://localhost:3000`  
  を設定すると、相互リンクで行き来できる。

## 4. 付箋ボード ＋ AI-Board をまとめて起動（推奨）

プロジェクトルートで実行すると、付箋ボード（3000）と AI-Board（5000）が別ウィンドウで起動する。

```powershell
cd wlinko-pj
.\start_all_servers.ps1
```

- **付箋ボード**: <http://localhost:3000>  
- **AI-Board**: <http://localhost:5000>  

---

## 5. 付箋ボード ＋ Board System を両方使う場合の起動順

1. **ターミナル1: Board System バックエンド**

   ```powershell
   cd board-system\backend
   .venv\Scripts\Activate.ps1
   uvicorn app.main:app --reload --port 8000
   ```

2. **ターミナル2: 付箋ボード（3000）**

   ```powershell
   cd 02_1_sticky-note\src
   npm run dev
   ```

3. **ターミナル3: Board System フロント（3001）**

   ```powershell
   cd board-system\frontend
   npm run dev -- -p 3001
   ```

4. ブラウザ  
   - 付箋ボード: <http://localhost:3000（トップの「Board> System を開く」で 3001 へ）  
   - Board System: <http://localhost:3001（ナビの「付箋ボード（旧）」で> 3000 へ）

## 6. ポート一覧・トラブルシューティング

| ポート | 用途 |
| -------- | ------ |
| 3000 | 付箋ボード（02_1）または Board System フロント（単体時） |
| 3001 | Board System フロント（付箋ボード併用時） |
| 5000 | AI-Board（Flask） |
| 8000 | Board System バックエンド（FastAPI） |

### ポート使用確認（Windows）

```powershell
netstat -ano | findstr :3000
netstat -ano | findstr :8000
```

### プロセス終了

```powershell
taskkill /PID <プロセスID> /F
```
