# デプロイ・運用ドキュメント 索引

付箋ボード（02_1_sticky-note）と Board System（Wonder Rinko）のデプロイ・運用に関連するドキュメントの一覧です。**どの手順を使うか**は下表で判断してください。

---

## どのドキュメントを読むか

| やりたいこと | 読むドキュメント |
|--------------|------------------|
| **本番を Docker でデプロイする**（推奨・Blue/Green） | [本番デプロイ手順_Docker.md](本番デプロイ手順_Docker.md) |
| **本番を Docker なしでデプロイする**（PM2 + Nginx） | [本番デプロイ手順.md](本番デプロイ手順.md) |
| **手元の PC で Docker を動かして試す** | [../ローカルDockerでテストする手順.md](../ローカルDockerでテストする手順.md) |
| **本番の .env や連携先の目安** | [本番設定の目安.md](本番設定の目安.md) |
| **board-system 配下の構成・deploy 要約** | [../board-system/DEPLOY.md](../board-system/DEPLOY.md) |

---

## ドキュメントの役割

| ドキュメント | 役割 |
|--------------|------|
| **本番デプロイ手順_Docker.md** | Docker 本番の**唯一の詳細手順**。初回デプロイ・通常デプロイ・ロールバック・運用・トラブルシューティングを一通り扱う。 |
| **本番デプロイ手順.md** | 非 Docker（PM2 + systemd + Nginx）での本番デプロイ。Docker を選ばない場合に参照。 |
| **ローカルDockerでテストする手順.md** | 開発 PC で `docker compose up` して動作確認する手順。本番サーバは不要。 |
| **本番設定の目安.md** | AI-Board・付箋ボード・Board System・Desktop の本番用 .env や URL の目安。Docker / 非 Docker の違いに注意。 |
| **board-system/DEPLOY.md** | Docker 本番の**要約**と board-system ディレクトリの構成。詳細は本番デプロイ手順_Docker.md へリンク。 |

---

## Docker と非 Docker の違い（本番）

| 項目 | Docker 本番 | 非 Docker 本番 |
|------|-------------|----------------|
| 付箋ボードの URL | http://wl-sticky-note.local/**board/**（例: /board/wl） | http://wl-sticky-note.local/ |
| Board System フロント | http://wl-sticky-note.local/**boards/**（例: /boards/taskboard） | http://wl-sticky-note.local/**boards/** |
| Board System API | http://wl-sticky-note.local/**api/bs/** | http://wl-sticky-note.local/**boards-api/** |
| DB | PostgreSQL（Docker） | SQLite（board.db） |

詳細は各デプロイ手順を参照してください。
