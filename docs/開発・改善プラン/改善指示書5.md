# 目的
`index.html` のVRMアバターに、「音声に合わせたリップシンク（口パク）」と「テキストタグによる表情変化」の機能を実装してください。

# 実装タスク

## 1. リップシンク (Audio Analysis)
`socket.on('ai_comment')` で音声URLを受け取って再生する部分を拡張し、Web Audio APIを使用して音量を解析してください。

- **AudioContextの作成:** ユーザーのクリック（`unmute-btn`）をトリガーに `AudioContext` を初期化または再開する（ブラウザの自動再生制限対策）。
- **AnalyserNode:** 再生する `<audio>` 要素からメディアソースを作成し、`AnalyserNode` に接続してリアルタイムの波形データを取得する。
- **VRMへの適用:** `animate()` ループ内で音量（平均ボリューム）を計算し、`currentVrm.expressionManager.setValue('aa', volume)` に適用して口を動かす。感度は適宜調整する。

## 2. 感情コントロール (Emotion System)
AIのコメントテキストから感情タグを解析し、VRMの表情を変更する関数 `setEmote(tagName)` を作成・適用してください。

- **タグ解析:** `socket.on('ai_comment')` で受信した `data.comment` から `[JOY]`, `[FUN]`, `[SORROW]`, `[ANGRY]`, `[SURPRISE]` などの文字列を正規表現で検出する。
- **表情適用:**
  - `[JOY]`, `[FUN]` -> VRM Preset: `happy`
  - `[SORROW]`, `[SAD]` -> VRM Preset: `sad`
  - `[ANGRY]` -> VRM Preset: `angry`
  - `[SURPRISE]` -> VRM Preset: `surprised` (なければ `happy` + 目を見開く)
  - `[NEUTRAL]` またはタグなし -> VRM Preset: `neutral`
- **リセット:** 音声再生が終わったら（あるいは一定時間後）、表情を `neutral` に徐々に戻す処理を入れる。

## 3. コードの統合
既存の `<script type="module">` 内にある `animate` ループや Socket.IO の受信処理を上記ロジックに合わせて書き換えてください。
