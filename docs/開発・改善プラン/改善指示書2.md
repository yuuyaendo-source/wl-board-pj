# 目的
現在開発中の `sticky_note_detector.py` において、キャリブレーション調整（HSVスライダー操作や四隅クリック）の動作が重いため、パフォーマンスを改善したいです。

# 現状の問題
- 高解像度のフレームに対してそのまま画像処理や描画を行っているため、GUIの応答が遅い。

# 指示：リサイズ処理の導入
OpenCVの処理フローを以下の「2層構造」にリファクタリングしてください。

1. **データ用（Original Frame）**
   - カメラから取得した生解像度の画像。
   - 最終的な付箋の切り出し（OCR用）や、座標計算のベースとして保持する。

2. **表示・調整用（Preview Frame）**
   - 処理の最初に、幅 `960px` 程度にリサイズした軽量なコピーを作成する。
   - **HSV色検知のプレビュー:** この軽量フレームに対して `cv2.cvtColor` や `cv2.inRange` を行い、スライダー操作時のリアルタイム性を確保する。
   - **四隅のクリック:** この軽量フレーム上でマウス入力を受け付ける。

3. **座標の変換（重要）**
   - 軽量フレーム上で取得した四隅の座標 `(x, y)` を、**元の解像度に合わせてスケールバック（拡大換算）** するロジックを追加してください。
   - 例: `original_x = preview_x * (original_width / preview_width)`

# 要件
- コードはクラス設計 (`StickyNoteDetector` など) を維持し、読みやすくすること。
- メインループ内では、表示用処理を軽量フレームで行い、最後に `cv2.imshow` する流れにすること。
