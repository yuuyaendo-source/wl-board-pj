# 改善計画14：ウイルス誤検知（False Positive）対策とセキュリティ適正化の実装完了報告

ご依頼いただいた「改善計画14：ウイルス誤検知（False Positive）対策とセキュリティ適正化の実装プラン」に基づく、`pynput` からOS標準APIへの完全移行、自動スタートアップ登録のオプトイン化、およびビルドプロセスのクリーンナップ機構の実装が完了いたしました。

## 実施した変更の詳細

1. **グローバルキーフック (`pynput`) の廃止とOS標準API（`RegisterHotKey`）への移行**
   - **`mini_port.py` の改修**: キーロガーとして誤検知される最大の要因であった `pynput` ライブラリを完全に排除し、Windows OS標準の `ctypes.windll.user32.RegisterHotKey` とスレッドメッセージキュー（`GetMessageW`）を利用した軽量で安全なホットキー監視（`Ctrl+Shift+Space`）へと移行しました。
   - **競合ハンドリング**: 他のアプリケーションが既に同じショートカットキーを使用している場合でも、エラーでクラッシュすることなく安全にスキップ・起動できる保護処理を組み込みました。

2. **自動スタートアップ登録ロジックの適正化（オプトイン化）**
   - **`app.py` の改修**: アプリ起動時にユーザーの明示的な許可なくレジストリ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）へ自動登録を行う処理は、マルウェアの永続化（Persistence）挙動と判定されやすいため完全に削除しました。
   - **設定UIへの一本化**: デフォルト状態を「自動起動オフ」とし、ユーザーが希望する場合にのみ設定画面（`settings_dialog.py`）から明示的にオンにする方式に統一することで、セキュリティソフトからの評価低下リスクを払拭しました。

3. **ビルドプロセス (`build_msi.ps1` / `setup.py`) の浄化と自動検証機構の追加**
   - **パッケージ設定のクリーンナップ**: `requirements.txt` から `pynput` を削除し、`setup.py` の `includes` および `packages` からも確実に取り除いた上で、再混入を防止するために `excludes` に明示的に追加しました。
   - **ビルドスクリプトの強化**: `build_msi.ps1` において、ビルド実行前に仮想環境から `pynput` を強制アンインストールする処理（`pip uninstall -y pynput`）と、ビルド成果物の中に `pynput` 関連ファイルが残存していないかを検証する自動チェック処理を追加しました。残存が検出された場合はビルドを安全に中断します。

## 確認方法

1. **ビルド成果物のクリーン確認とスキャン**:
   - `build_msi.ps1` を実行し、コンソールに `pynput exclusion check: OK (not bundled)` と表示され正常にビルドが完了することを確認してください。
   - 出力された `dist\WonderLinko.msi` に対して Windows Defender 等のセキュリティソフトでスキャンを実施し、`Trojan:Win32/Bearfoos.A!ml` などの誤検知が発生しないことを確認してください。
2. **ホットキーの動作確認**:
   - アプリを起動し、非アクティブな状態からキーボードの `Ctrl+Shift+Space` を押下した際、ミニポートが正常に前面表示されることを確認してください。
3. **スタートアップ設定の動作確認**:
   - アプリの初回起動時に、レジストリに自動起動の設定が勝手に追加されないことを確認してください。
   - 設定画面から「PC起動時に自動で起動 (Windows)」を切り替えた場合のみ、正常にレジストリへの登録・解除が行われることを確認してください。
