# タスクボードの列統合および重要マーク追加計画

タスクボード（Task Board）のユーザー体験と表示ロジックを改善するため、ご要望の3点について以下の実装プランを提案します。

## Proposed Changes

### Frontend Component

#### [MODIFY] [page.tsx](file:///c:/Users/yuuya/Documents/dev/wl-board-pj/board-system/frontend/app/taskboard/page.tsx)

- タスクボードの列定義（`COLUMNS`）を以下の4列に再構成します。
  1. `アイデア` (AI判定による第1象限)
  2. `タスク` (旧「短期タスク」「長期タスク」「重要」を統合)
  3. `応援要請・未振り分け` (新規追加)
  4. `完了` (完了済み)
- **「応援要請・未振り分け」列の表示ロジック**:
  - 各付箋の色情報などを元に判定します。具体的には、応援要請（`task_color === "red"`）または未割り当て（`task_color === "yellow"`）のものをこの列に集約します。
  - 列内のソート順を変更し、応援要請（red）が常に上部に来るようにします。
- **ドラッグ＆ドロップ（状態遷移）の制御**:
  - 新設する「応援要請・未振り分け」列は、システムが状態（未アサインまたは応援要請）を元に自動で振り分ける表示専用（または引き抜き専用）の列とするため、手動でこの列にドロップして状態をリセットする操作は不可（ドロップ禁止）とします。

#### [MODIFY] [NoteCard.tsx](file:///c:/Users/yuuya/Documents/dev/wl-board-pj/board-system/frontend/app/components/NoteCard.tsx)

- 旧「重要」列（`matrix_quadrant === 4`）に分類される付箋について、カード右上のバッジ領域に「⭐（または「重要」などのラベル）」を視覚的に表示する処理を追加します。

## User Review Required

> [!IMPORTANT]
> **「応援要請・未振り分け」へのドラッグ＆ドロップについて**
> この列は付箋の「アサイン状況」と「応援状態」から自動判定して表示する列です。
> そのため、「タスク」列などからこの列に手動でドラッグして戻す（＝担当を外す）操作は、今回のUI上では**不可（ドロップ禁止）**とする想定ですがよろしいでしょうか？（担当から外れる操作は、これまで通りパーソナルボード側での削除・完了やゴミ箱への移動で行う想定です）

> [!NOTE]
> **重要マークのデザイン**
> 現在の提案では、付箋右上のバッジ（カレンダーやAIのアイコンが並ぶ箇所）に「⭐」アイコン（背景色オレンジ等）を表示することを想定しています。デザインに特別なご希望があればお知らせください。

## Verification Plan

### Manual Verification

1. フロントエンドを起動し、`/taskboard` ページを開く。
2. 「アイデア」「タスク」「応援要請・未振り分け」「完了」の4列が表示されていることを確認する。
3. 誰のボードにも無い未割り当てのタスク（黄）と、応援要請中のタスク（赤）が「応援要請・未振り分け」列に表示され、応援要請が上部にくることを確認する。
4. 重要度の高いタスク（AI判定による第4象限のタスク）の付箋に「⭐」バッジが表示されていることを確認する。
