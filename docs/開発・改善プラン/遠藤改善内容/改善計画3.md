# 「チーム」概念の追加およびチーム管理・一括コピー機能・デプロイスクリプト改修の実装計画

チーム（「ネットワーク」「構築」など）の概念をシステム全体に追加し、タスクボード上の付箋をチームエリアにドロップすることで、該当チーム所属メンバー全員のパーソナルボードへ付箋を一括コピーする機能を実装します。

本計画では、既存のメンバーSeed処理方式（`db.py` の `seed_personal_users`）に合わせたチーム初期データ生成、既存のメンバー管理GUIに倣ったチームの追加・編集・削除およびチームメンバーの編集を行えるGUI管理機能、ならびに**本番・ステージング用 Alembic マイグレーションおよびデプロイスクリプト (`deploy.sh`, `deploy-staging.sh`) の更新**を含みます。

---

## 既存処理の確認結果

1. **Seed処理**
   - 既存メンバーは [db.py](file:///c:/Users/yuuya/Documents/dev/wl-board-pj/board-system/backend/app/db.py) の `PERSONAL_USER_NAMES` 配列を元に、起動時 (`main.py` の `lifespan`) に `seed_personal_users()` が実行され、存在しない場合のみ自動追加されています。
   - チームに関しても同様に `SEED_TEAMS = ["ネットワーク", "構築"]` を定義し、`seed_teams()` を `lifespan` 起動時に実行する構成とします。また、既存初期ユーザー（ID 1〜7）の `team_id` が未設定の場合に初期割り当て（奇数ID: ネットワーク, 偶数ID: 構築）を行います。

2. **メンバーGUI管理**
   - フロントエンドの [AddUserMenu.tsx](file:///c:/Users/yuuya/Documents/dev/wl-board-pj/board-system/frontend/app/components/AddUserMenu.tsx) にてメンバーの追加・編集・削除機能が提供されています。
   - これを拡張し、「チームの追加・編集・削除」および「メンバーの所属チーム変更」を行えるようにGUIを統合・強化します。

3. **デプロイ・DBマイグレーション**
   - [deploy.sh](file:///c:/Users/yuuya/Documents/dev/wl-board-pj/board-system/deploy/deploy.sh) および [deploy-staging.sh](file:///c:/Users/yuuya/Documents/dev/wl-board-pj/board-system/deploy/deploy-staging.sh) にて `alembic upgrade head` が実行されるため、Alembic マイグレーションファイルを作成します。
   - マイグレーション後に `scripts/seed_teams.py` を実行するステップを両スクリプトに追加します。
