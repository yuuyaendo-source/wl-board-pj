# 改善計画14：ウイルス誤検知（False Positive）対策とセキュリティ適正化の実装プラン

## 1. 概要・目的
Windows Defender等のセキュリティソフトにおいて、デスクトップアプリ（`WonderLinko.exe` または MSIインストール後の実行ファイル）が「`Trojan:Win32/Bearfoos.A!ml`」などのマルウェアとして誤検知（False Positive）される問題を解決します。
セキュリティソフトの機械学習（ML）モデルに「悪意のある挙動」としてスコアリングされやすいコードのパターンを排除・適正化し、社内PCでブロックされることなく安全に常駐できる状態にします。

---

## 2. 誤検知の根本原因（現状の課題）

以下の3つの要素が組み合わさることで、ヒューリスティック検知（振る舞い検知）に引っかかっています。

1. **グローバルキーフック (`pynput`)**
   - `mini_port.py` にて、アプリが非アクティブな状態でも `Ctrl+Shift+Space` を検知するために `pynput.keyboard.GlobalHotKeys` を使用しています。この「バックグラウンドでのキー入力を常時監視する」挙動が、キーロガー（入力盗聴ソフト）のパターンと酷似しています。
2. **起動時のサイレントなレジストリ書き換え (`app.py` / `startup.py`)**
   - `app.py` の起動時処理において、ユーザーの明示的な許可なく `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に自分自身を登録しています。これがトロイの木馬による「永続化（Persistence）」の手口と判定されます。
3. **スタンドアロン化ツール（PyInstaller / cx_Freeze）の特性**
   - PythonスクリプトをEXE化するツール自体が、過去に多くのマルウェアで悪用されているため、生成されたバイナリの初期信頼スコアが低く設定されています。

---

## 3. 具体的な実装仕様 (Proposed Changes)

### ① グローバルキーフック機能の完全な切り離しと同梱回避
誤検知の最大要因であるキーボード監視ライブラリを標準構成およびビルド設定から完全に排除します。

* **`requirements.txt` の修正**:
  - `pynput>=1.7.6` を削除またはコメントアウトします。
* **`setup.py` の修正（重要）**:
  - `build_exe_options` 内の `includes` および `packages` にハードコードされている `"pynput"` を削除します。
  - 既存環境のキャッシュからの混入を確実に防ぐため、`excludes` リストに `"pynput"` を明示的に追加します。
* **フォールバックメッセージの整理 (`mini_port.py`)**:
  - `pynput` インポート失敗時の処理を維持しつつ、ユーザーにインストールを促すメッセージを適正化します。
  - 変更前: `print("Linko Mini-Port: pynput が未インストールです。pip install pynput で Ctrl+Shift+Space が有効になります。")`
  - 変更後: `print("Linko Mini-Port: セキュリティ適正化のため、グローバルホットキー機能は無効化されています。")`

### ② 自動スタートアップ登録の無効化（ユーザー同意型への変更）
バックグラウンドでのサイレントなレジストリ操作を廃止し、「設定ダイアログ」からユーザーが手動でONにした場合のみレジストリに書き込む設計へ完全移行します。

* **`app.py` の修正**:
  - 初回起動時判定と自動スタートアップ登録を行っている以下のロジックを削除またはコメントアウトします。
  ```python
  # 削除またはコメントアウト対象 (app.py)
  # if (
  #     sys.platform == "win32"
  #     and getattr(sys, "frozen", False)
  #     and not startup.is_startup_enabled()
  # ):
  #     if startup.set_startup_enabled(True): ...
  ```

### ③ ユーザー影響の周知とドキュメント更新
* **`README.md` の修正（存在する場合）**:
  - 「Ctrl+Shift+Spaceでミニポートを呼び出す」旨の記載を削除し、今後は「タスクトレイアイコンのクリック、または設定メニューから表示」する運用へ移行した旨を追記します。

### ④ （運用面）配布時のデジタル署名またはホワイトリスト登録
コードの修正で根本的なスコアは改善しますが、完全な回避には運用面の補助も推奨します。

* **配布スクリプトへのコメント追記 (`build_msi.ps1`)**:
  - 本格的な社内展開時は、生成された `.msi` および中の `.exe` に対して Authenticode デジタル署名を付与するステップを将来的に組み込む旨をドキュメント化します。
  - または、Microsoft Security Intelligence への誤検知申請（False Positive Submission）を行う運用フローを定めます。
  - 既存の開発仮想環境（`.venv`）で作業する場合、`pip uninstall -y pynput` を手動実行するよう案内を追記します。

## 5. 検証計画 (Verification Plan)

### Automated / Build Tests
1. **ビルド成功の確認**:
   - `build_msi.ps1` を実行し、`pynput` への参照エラーなどが発生せずに完了することを確認する。
2. **成果物への `pynput` 混入チェック**:
   - ビルド完了後、出力フォルダ内に `pynput` が残存していないことをPowerShell等で確認する。
   ```powershell
   Get-ChildItem -Path "build" -Recurse -Filter "*pynput*"
   # 結果が0件であることを確認
   ```

### Manual Verification
1. **Windows Defender による即時コマンドラインスキャン**:
   - GUIでの警告を待つだけでなく、DefenderのCLIツールでビルド成果物（MSI）を直接スキャンし、誤検知判定が解消されたことを確認する。
   ```powershell
   & "C:\Program Files\Windows Defender\MpCmdRun.exe" -Scan -ScanType 3 -File (Resolve-Path "dist\WonderLinko.msi")
   ```
2. **キーフック除去の動作確認**:
   - アプリを起動し、コマンドプロンプト等で「セキュリティ適正化のため、グローバルホットキー機能は無効化されています。」というメッセージが出力されること。
   - エラーなくミニポートやタスクトレイアイコンが表示され、通常通り動作すること。
3. **スタートアップ登録の動作確認**:
   - アプリを初回起動した際、勝手にレジストリ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）へ値が書き込まれないことを確認する。
   - タスクトレイの「設定...」から「PC起動時に自動で起動」にチェックを入れて保存した際、初めてレジストリに値が書き込まれることを確認する。
