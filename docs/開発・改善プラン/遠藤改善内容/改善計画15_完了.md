# 改善計画15：ウイルス誤検知（Bearfoos.A!ml）の抜本的対策とアーキテクチャ適正化 完了報告

ご依頼いただいた「改善計画15：ウイルス誤検知（Bearfoos.A!ml）の抜本的対策とアーキテクチャ適正化」に基づく、`ctypes` 呼び出しおよび関連する Win32 API 依存の全廃、レジストリ操作によるスタートアップ登録の廃止、およびビルド構成の適正化作業がすべて完了いたしました。

---

## 実施した変更の詳細

### 1. `ctypes` への依存と Win32 API 呼び出しの全廃
- **二重起動防止ロジックの変更 (`app.py`)**:
  - `ctypes` と `CreateMutexW` によるミューテックス作成を完全に削除しました。
  - 代替として、ローカルループバックアドレス (`127.0.0.1`) の特定ポートへの排他バインド (`socket.bind`) を用いた単一インスタンス制御へ変更し、OS レベルの安全かつクリーンな排他制御を実現しました。
- **プロセス終了待機の変更 (`app.py`)**:
  - `_wait_for_process_exit` 内で使用していた `OpenProcess` や `WaitForSingleObject` 等の Win32 API ブロックを削除しました。
  - フォールバックとして用意されていた `os.kill(pid, 0)` と `time.sleep()` を用いた生存チェックループへ完全に一本化しました。
- **グローバルホットキーの仕様変更 (`mini_port.py`)**:
  - `RegisterHotKey` や `GetMessageW` を用いたバックグラウンドでのキーボード入力監視処理を完全に削除しました。
  - 脅威スコアを引き上げる要因であった「Ctrl+Shift+Space」によるグローバル呼び出し機能を廃止し、操作を通知領域アイコン等へ誘導するよう仕様を見直しました。

### 2. スタートアップ登録（レジストリ操作）の廃止と適正化
- **自動起動登録の適正化 (`startup.py`)**:
  - `winreg` を用いたレジストリ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）への直接書き込み処理を全廃しました。
  - 代替として、Windows の「スタートアップ」フォルダ（`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`）へ、`win32com.client` 経由でショートカット（`.lnk`）を配置・削除する方式に変更し、OS の標準的なスタートアップ管理機構に準拠させました。

### 3. インストールパスとビルド構成の見直し
- **診断ログパスの変更 (`app.py`, `app_log.py`)**:
  - `exe_dir` (実行ファイルと同じディレクトリ) への直接書き込みを避け、`%LOCALAPPDATA%\WonderLink` 配下に `WonderLinko.log` や診断ログファイルを出力・監視するよう変更しました。
- **Program Files へのインストール変更 (`setup.py`)**:
  - `bdist_msi_options` において、`all_users: True` を指定し、インストール先 (`initial_target_dir`) を `[ProgramFilesFolder]\WonderLink\WonderLinko` に変更しました。
  - ユーザー領域（AppData）での実行を避け、信頼度の高いシステム領域での稼働を標準としました。
  - `includes` に `win32com` などの依存を追加しました。

## 確認方法

1. **マルウェア誤検知の解消確認**:
   - `build_msi.ps1` を実行して生成した `dist\WonderLinko.msi` をインストールし、`C:\Program Files\WonderLink\WonderLinko\WonderLinko.exe` が Windows Defender (最新の定義ファイル) で「`Trojan:Win32/Bearfoos.A!ml`」として誤検知・ブロックされないことを確認してください。
2. **二重起動防止の動作確認**:
   - アプリを起動中に、もう一つアプリを起動しようとした際、二重起動が正しくブロック（または既存のウィンドウが前面化）され、不要なエラーが出ないことを確認してください。
3. **スタートアップ設定の動作確認**:
   - 設定ダイアログから「PC起動時に自動で起動」をオンにした際、レジストリではなく `shell:startup` フォルダ（Windows のスタートアップフォルダ）に `Wonder Linko.lnk` が作成されることを確認してください。
   - オフにした際に同ショートカットが正しく削除されることを確認してください。
