# 改善計画11：グレーアウト付箋の非表示切替およびホイールズーム機能の実装プラン（レビュー反映版）

付箋ボード（`wl-sticky-note`）におけるユーザー体験向上のため、グレーアウト（完了済み等）付箋のワンクリック表示／非表示切り替え機能、およびマウスホイール（スクロール）による直感的なキャンバス拡大・縮小（カーソル位置中心ズーム）機能を実装します。

---

## 1. 概要・変更目的

1. **グレーアウト付箋の切り替え機能**
   - Board Systemでのゴミ箱移動や完了処理によりグレーアウトされた付箋について、ワンクリックで表示／非表示をトグル可能にし、キャンバス上の視認性・整理しやすさを向上させます。
   - 付箋一覧パネル（`CommentListPanel`）との連携や、プロパティ命名の揺らぎに対する堅牢性を備えた設計とします。
2. **ホイール操作による拡大・縮小（ホイールズーム）機能**
   - マウスホイールおよびトラックパッドでのスクロール操作による拡大・縮小を導入します。
   - マウスポインタの位置を中心としたスムーズなズーム処理、テキスト入力欄やモーダル操作との干渉を防ぐイベントガード、およびツールバーとのズーム倍率範囲の統一を行います。

---

## 2. 具体的な実装仕様

### ① グレーアウト付箋の表示／非表示切り替えと連携仕様

#### `src/app/board/[id]/page.js`
* **状態管理**:
  グレーアウト付箋の非表示フラグ `hideGrayNotes`（`boolean`、初期値: `false`）をステートとして追加します。
  ```javascript
  const [hideGrayNotes, setHideGrayNotes] = useState(false);
  ```
* **堅牢な判定ロジック（防御的プログラミング）**:
  プロパティ命名の揺らぎ（`gray`, `is_gray`, `isGray`）に対処するため、判定ヘルパー関数を定義します。
  ```javascript
  const isGrayNote = (note) => Boolean(note?.gray || note?.is_gray || note?.isGray);
  ```
* **描画対象のフィルタリング**:
  `BoardCanvas` および `CommentListPanel` に渡す付箋リストを、`hideGrayNotes` が `true` の場合はグレー付箋を除外して渡します。
  ```javascript
  const visibleNotes = hideGrayNotes 
    ? notes.filter(n => !isGrayNote(n)) 
    : notes;
  ```
* **付箋一覧パネルからのジャンプ時制御**:
  コメント一覧からグレー付箋がクリックされた場合、自動的に `hideGrayNotes` を `false`（表示状態）へ切り替えて該当付箋へフォーカス移動を行います。

#### `src/components/Toolbar.js` & `Toolbar.module.css`
* **UIコントロール**:
  ツールバーの機能アイコンエリアに「グレー付箋の表示/非表示」切替ボタンを追加します。
* **ボタンデザイン**:
  - 表示中: `👁️` / ツールチップ「グレー付箋を隠す」
  - 非表示中: `🙈` / ツールチップ「グレー付箋を表示」
* **Props追加**: `hideGrayNotes`, `onToggleHideGrayNotes` を受け取り、クリック時にトグル処理を呼び出します。

### ② マウスホイールによる拡大・縮小（カーソル中心ズーム）

#### 定数定義（ズーム範囲の統一）
ツールバーとホイールズームで許容範囲を統一するため、スケール制限の定数を定義・共有します。
```javascript
export const MIN_SCALE = 0.3;
export const MAX_SCALE = 2.5;
```

#### `src/app/board/[id]/page.js`
* **イベントガードと連続的ズーム計算**:
  - `textarea` や `input` などの入力エリア、ダイアログ、およびスクロール可能要素内でのホイール操作時はズームをスキップします。
  - `e.deltaY` に応じた指数的計算 `Math.exp(-e.deltaY * 0.0015)` を採用し、一般的なマウスホイールとトラックパッド（微小 deltaY 高頻度）の双方で滑らかなズームを実現します。

```javascript
useEffect(() => {
    const container = boardContainerRef.current;
    if (!container) return;

    const handleWheel = (e) => {
        // テキスト入力エリア・モーダル・スクロール可能エリアでのスクロール時はズームを除外
        if (e.target.closest('textarea, input, select, [data-scrollable="true"]')) {
            return;
        }

        e.preventDefault();

        // deltaY に応じた連続的なスムーズズーム計算（トラックパッド・マウス双方に対応）
        const zoomFactor = Math.exp(-e.deltaY * 0.0015);
        
        setScale((prevScale) => {
            const newScale = Math.min(Math.max(MIN_SCALE, prevScale * zoomFactor), MAX_SCALE);
            if (Math.abs(newScale - prevScale) < 0.001) return prevScale;

            // マウスカーソルのコンテナ内相対座標
            const rect = container.getBoundingClientRect();
            const mouseX = e.clientX - rect.left;
            const mouseY = e.clientY - rect.top;

            // ズーム前のキャンバス内座標
            const targetX = (container.scrollLeft + mouseX) / prevScale;
            const targetY = (container.scrollTop + mouseY) / prevScale;

            // 新スケール適用後のスクロール位置を計算・適用
            requestAnimationFrame(() => {
                container.scrollLeft = targetX * newScale - mouseX;
                container.scrollTop = targetY * newScale - mouseY;
            });

            return newScale;
        });
    };

    container.addEventListener("wheel", handleWheel, { passive: false });
    return () => {
        container.removeEventListener("wheel", handleWheel);
    };
}, []);
```

## 4. 検証計画

### 手動動作検証

1. **グレー付箋の表示切替およびパネル連携**:
   - グレーアウト付箋が存在するボード（例: `/board/wl`）を開く。
   - ツールバーの表示切替ボタンをクリックし、キャンバスおよびコメント一覧パネルからグレー付箋が一括で隠れることを確認。
   - 表示切り替え時や付箋ジャンプ時に、期待通りの表示制御が行われることを確認。

2. **ホイールズーム感度および操作干渉防止**:
   - 一般的なマウスホイールおよびトラックパッド操作で急激な跳ねが起きず、滑らかにズームされることを確認。
   - 付箋内の `textarea`（追記欄・編集欄）や `CommentListPanel` 内でホイール操作を行った際、内部スクロールが優先されキャンバスズームが誤発火しないことを確認。
   - ツールバーの 「＋」「−」 ボタン操作とホイールズーム操作の限界値（`0.3` ～ `2.5`）が一致していることを確認。
