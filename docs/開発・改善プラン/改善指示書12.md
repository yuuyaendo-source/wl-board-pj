## AIによる自動振り分け機能
以下のコードを参考に現状に合わせて実装

**実装済み**: `board-system/backend/app/services/orchestrator.py` に集約。`create_sticky_note` から `process_new_note_ai(note_id, db)` を呼び出し。Task 列は 1=アイデア・2=短期・3=長期・4=重要 にアイゼンハワー象限をマッピング（EISENHOWER_TO_COLUMN）。Triage 失敗時は Task にアイデア(1)で配置する安全策を採用。

---

## AI自動振り分けの確認方法

1. **前提**
   - バックエンドの `board-system/backend/.env` に **`GEMINI_API_KEY`** を設定する（未設定だと Triage が動かず、付箋は Task の「アイデア」にだけ置かれる安全策で終わる）。
   - バックエンドを起動したターミナルで、ログに **`[Rinko AI]`** が出るか確認する。

2. **トリガー**
   - **Main ボード**（`/main`）の 1 行入力で付箋を投稿する  
     または  
   - **パーソナルボード**の 1 行入力で付箋を投稿する  
   → いずれも `POST /sticky_notes` が呼ばれ、その中で `process_new_note_ai` が実行される。

3. **確認手順（タスク判定）**
   - Main で「明日までにレポート提出」のように**タスクっぽい文**を投稿する。
   - **Task ボード**（`/task`）を開き、該当付箋が **アイデア・短期・長期・重要のいずれかの列**に自動で入っているか確認する。
   - **タスクでない**文（例:「今日はいい天気」）を投稿すると、Main にだけ残り Task には出ない（ログに `NOT a task` と出る）。

4. **確認手順（担当者 → Personal）**
   - users に存在する名前（例: 堀、浅川）を本文に含めて投稿する（例:「堀さん：来週打ち合わせお願いします」）。
   - 該当ユーザーの **パーソナルボード**（`/personal/hori` など）の **タスク（INBOX）** に、同じ付箋が自動で入っているか確認する。

5. **ログで確認**
   - バックエンドを `uvicorn app.main:app --reload --port 8000` で起動したターミナルで、投稿のたびに次のようなログが出る。
     - `[Rinko AI] Processing Note ID: N...`
     - `[Rinko AI] Scored Note N: U=..., I=... -> Eisenhower ... -> Column ...`
     - 担当者を割り当てた場合: `[Rinko AI] Assigning to user: ...`
     - `[Rinko AI] Finished processing Note N.`
   - API キー未設定や Triage 失敗時: `[Rinko AI] Triage failed or API key missing. Placing on Task as アイデア(1).`

backend/app/services/orchestrator.py（参考コード）

import logging
from sqlalchemy.orm import Session
from app.models.sticky_note import StickyNote
from app.models.board_placement import BoardPlacement, BoardType, Lane
from app.models.user import User
from app.ai.triage import run_triage
from app.ai.matrix import run_matrix_scoring

# ログ設定
logger = logging.getLogger("uvicorn")

def process_new_note_background(note_id: int, db: Session):
    """
    バックグラウンド処理:
    1. 新規付箋の内容をAI解析 (Triage)
    2. タスクなら緊急度・重要度を採点 (Matrix Scoring)
    3. Taskボードの適切な列（象限）に自動配置
    4. 担当者がいればPersonalボードにも配布
    """
    logger.info(f"[Rinko AI] Processing Note ID: {note_id}...")
    
    note = db.query(StickyNote).filter(StickyNote.id == note_id).first()
    if not note:
        logger.error(f"[Rinko AI] Note {note_id} not found.")
        return

    content = note.content

    # --- 1. AI仕分け (Triage) ---
    triage_result = run_triage(content)
    if not triage_result:
        logger.warning("[Rinko AI] Triage failed or API key missing.")
        # AIが動かない場合でも、とりあえず「アイデア（第4象限）」としてTaskボードに置いておく安全策
        # 必要なければ return してMainボードのみにする
        _place_on_task_board(db, note.id, 0, 0, 4) 
        db.commit()
        return

    # タスクでない（雑談など）場合は、Taskボードには置かずに終了（Mainボードのみに残る）
    if not triage_result.get("is_task"):
        logger.info(f"[Rinko AI] Note {note_id} is judged as NOT a task.")
        # 明示的に「アイデア」列に入れたい場合はここを通す
        # _place_on_task_board(db, note.id, 0, 0, 4) 
        return

    # --- 2. AI採点 (Matrix Scoring) ---
    matrix_result = run_matrix_scoring(content)
    
    urgency = 50
    importance = 50
    quadrant = 4 # デフォルト: アイデア列

    if matrix_result:
        urgency = matrix_result.get("urgency", 50)
        importance = matrix_result.get("importance", 50)
        # マトリクスロジック:
        # 1: 重要(右上), 2: 長期(左上), 3: 短期(右下), 4: アイデア(左下)
        quadrant = matrix_result.get("matrix_quadrant", 4)

    logger.info(f"[Rinko AI] Scored Note {note_id}: U={urgency}, I={importance} -> Quadrant {quadrant}")

    # --- 3. Taskボードへ配置 ---
    _place_on_task_board(db, note.id, float(urgency), float(importance), quadrant)

    # --- 4. Personalボードへ配布（担当者がいる場合） ---
    assignee_name = triage_result.get("assignee_name")
    if assignee_name:
        # 部分一致でユーザー検索 (例: "田中" -> "田中 太郎")
        target_user = db.query(User).filter(User.name.contains(assignee_name)).first()
        if target_user:
            logger.info(f"[Rinko AI] Assigning to user: {target_user.name}")
            personal_placement = BoardPlacement(
                note_id=note.id,
                board_type=BoardType.PERSONAL,
                owner_id=target_user.id,
                lane=Lane.INBOX # Inboxにお届け
            )
            db.add(personal_placement)
        else:
            logger.warning(f"[Rinko AI] Assignee '{assignee_name}' not found in DB.")

    db.commit()
    logger.info(f"[Rinko AI] Finished processing Note {note_id}.")


def _place_on_task_board(db: Session, note_id: int, x: float, y: float, q: int):
    """Taskボードへの配置ヘルパー（重複チェック付き）"""
    existing = db.query(BoardPlacement).filter(
        BoardPlacement.note_id == note_id,
        BoardPlacement.board_type == BoardType.TASK
    ).first()

    if not existing:
        placement = BoardPlacement(
            note_id=note_id,
            board_type=BoardType.TASK,
            position_x=x,
            position_y=y,
            matrix_quadrant=q
        )
        db.add(placement)
    else:
        # 既に存在する場合は位置を更新（AIによる再評価など）
        existing.position_x = x
        existing.position_y = y
        existing.matrix_quadrant = q
