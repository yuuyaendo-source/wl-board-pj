指示:

sticky_note_detector.py の VideoStream クラス（または cv2.VideoCapture）の引数を、WebカメラID 0 から、以下のRTSP URL形式に変更できるようにしてください。

URL例: rtsp://admin:password@192.168.x.x:554/live/high

環境変数 .env から RTSP_URL を読み込み、設定があればそれを使用、なければ 0 (Webカメラ) を使う仕様にしてください。

解像度の違いへの対応:

Verkadaは解像度が非常に高い（4Kなど）ため、付箋検知のパラメータ（最小面積 min_area など）が今のままだと「小さすぎてゴミと判定される」可能性があります。

min_area などの閾値を、画面解像度に応じて自動調整するか、.env で設定できるようにしてください。
