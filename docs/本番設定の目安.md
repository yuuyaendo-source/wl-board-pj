# 本番設定の目安

本番（http://wl-sticky-note.local/board/wl）で連携する際の設定ファイルの目安です。

## 1. AI-Board（02_2_AI-Board）

| 項目 | 内容 |
|------|------|
| **設定例** | `02_2_AI-Board/.env.production.example` をコピーして `.env` にリネーム |
| **必須** | `OLLAMA_URL`（例: `http://172.16.1.251:11434/v1`）、`POSTIT_BOARD_URL=https://wl-ai-board.internal.wonder-link.co.jp` |
| **任意** | `RTSP_URL`（カメラ）、`MIN_AREA`、`VOICEVOX_*` |
| **config.json** | `src/config.json` の `board_id` を **`wl`** に（本番連携先） |

## 2. 付箋ボード（02_1_sticky-note / wl-sticky-note）

| 項目 | 内容 |
|------|------|
| **設定例** | `02_1_sticky-note/src/.env.production.example` をコピーして `src/.env` にリネーム |
| **必須** | `AI_BOARD_URL`＝AI-Board の URL（本番例: **`http://wl-ai-board.local`**）。HTTPS かつ自己証明書なら **`AI_BOARD_INSECURE_SSL=1`** も必須 |
| **任意** | `AI_BOARD_LINK_BOARD_IDS=wl`（デフォルトで wl）、`NODE_ENV=production`、`PORT=3000` |

## 3. Board System（board-system）

本番では付箋ボードと同一ドメイン（例: http://wl-sticky-note.local）で提供します。

- **Docker でデプロイする場合**: [本番デプロイ手順_Docker.md](本番デプロイ手順_Docker.md)。API は `/api/bs/`、フロントは `/boards/`。
- **非 Docker（PM2）でデプロイする場合**: [本番デプロイ手順.md](本番デプロイ手順.md)。API は `/boards-api/`、フロントは `/boards/`。

| 項目 | 内容（Docker 本番の例） |
|------|-------------------------|
| **バックエンド** | compose の環境変数で `POSTIT_BOARD_URL` 等。.env は `board-system/.env`。 |
| **フロント** | ビルド時に `NEXT_PUBLIC_API_URL=http://wl-sticky-note.local/api/bs`、`NEXT_PUBLIC_LEGACY_BOARD_URL=http://wl-sticky-note.local`。basePath は `/boards`（compose で指定）。 |
| **付箋ボード側** | compose で `NEXT_PUBLIC_BOARD_SYSTEM_URL=http://wl-sticky-note.local/boards` を指定すると Board System へのリンクが有効になる |

## 4. Desktopアプリ（02_3_WL_Desktop_app）

| 項目 | 内容 |
|------|------|
| **設定例** | `02_3_WL_Desktop_app/config.production.example.json` を参考に `config.json` を編集 |
| **本番** | `postit_board_url`: `http://wl-sticky-note.local/`、`postit_board_id`: `wl`、`ai_board_url`: AI-Board の URL（例: **`http://wl-ai-board.local/`**） |
| **通知** | `postit_poll_interval_sec`: 60 以上（0 だと新付箋通知なし） |
