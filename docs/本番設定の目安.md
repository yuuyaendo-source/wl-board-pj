# 本番設定の目安

本番（http://wl-sticky-note.local/board/wl）で連携する際の設定ファイルの目安です。

## 1. AI-Board（02_2_AI-Board）

| 項目 | 内容 |
|------|------|
| **設定例** | `02_2_AI-Board/.env.production.example` をコピーして `.env` にリネーム |
| **必須** | `GEMINI_API_KEY`、`POSTIT_BOARD_URL=http://wl-sticky-note.local` |
| **任意** | `RTSP_URL`（カメラ）、`MIN_AREA`、`VOICEVOX_*` |
| **config.json** | `src/config.json` の `board_id` を **`wl`** に（本番連携先） |

## 2. 付箋ボード（02_1_sticky-note / wl-sticky-note）

| 項目 | 内容 |
|------|------|
| **設定例** | `02_1_sticky-note/src/.env.production.example` をコピーして `src/.env` にリネーム |
| **必須** | `AI_BOARD_URL`＝AI-Board の URL。**HTTPS** の場合は `https://172.16.1.251:5000`。自己証明書なら **`AI_BOARD_INSECURE_SSL=1`** も必須（付けないと付箋・リン子が反応しない） |
| **任意** | `AI_BOARD_LINK_BOARD_IDS=wl`（デフォルトで wl）、`NODE_ENV=production`、`PORT=3000` |

## 3. Desktopアプリ（02_3_WL_Desktop_app）

| 項目 | 内容 |
|------|------|
| **設定例** | `02_3_WL_Desktop_app/config.production.example.json` を参考に `config.json` を編集 |
| **本番** | `postit_board_url`: `http://wl-sticky-note.local/`、`postit_board_id`: `wl`、`ai_board_url`: AI-Board のURL（例: `https://172.16.1.251:5000/`） |
| **通知** | `postit_poll_interval_sec`: 60 以上（0 だと新付箋通知なし） |
