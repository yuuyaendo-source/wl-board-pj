# Windows の通知をオフにしたあと、再度オンにする方法

Wonder Linko のトースト通知を Windows の設定で一度オフにすると、**アプリ側からはオンに戻せません**。アンインストールして再インストールしても、**Windows が「このアプリの通知はオフ」という設定を覚えている**ため、そのままでは通知は出ません。

## 対処方法（Windows の設定で通知をオンに戻す）

### Windows 11 の場合

1. **設定** を開く（Win + I など）
2. **システム** → **通知**
3. 「**通知を表示するアプリ**」または「**アプリの通知**」の一覧で、次のいずれかを探す：
   - **Wonder Linko**
   - **Wonder Rinko**
   - **WonderLinko.exe**
   - **Python**（exe の種類によって表示名が異なる場合があります）
4. 該当アプリのスイッチを **オン** にする
5. 一覧にアプリ名が出てこない場合：
   - いったん **「アプリやその他の送信者からの通知を取得する」** をオンにする
   - Wonder Linko を起動し、トレイメニューから **「テストお知らせ（付箋ボードURL付き）」** を実行する
   - 再度 設定 > システム > 通知 を開くと、アプリが一覧に表示されることがあります

### Windows 10 の場合

1. **設定** を開く
2. **システム** → **通知とアクション**
3. 「**送信ごとの通知の受信設定**」またはアプリ一覧で、上記と同様に **Wonder Linko / Wonder Rinko / WonderLinko** を探す
4. オフになっている場合は **オン** に変更する

### それでも表示されない場合

- **集中モード（応答不可モード）** がオンになっていないか確認する（タスクバー右下のベルアイコン）
- **通知の音** がミュートになっていないか確認する
- PC を再起動してから、もう一度「テストお知らせ」を試す

---

## アプリ一覧に出てこない場合（レジストリで通知設定をリセット）

設定の通知一覧に Wonder Linko が出てこない場合、**Windows が通知を「オフ」として覚えているレジストリを削除**すると、次回の通知から再有効化されることがあります。

### 方法A: 手動でレジストリを編集する

1. **レジストリエディター** を開く（スタートメニューで「regedit」と入力して実行。管理者権限の確認が出たら「はい」）
2. 次のキーに移動する：

   ```
   HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Notifications\Settings
   ```

3. その下の **サブキー** を確認する。次のような名前のキーがあれば、それが Wonder Linko の通知設定の可能性があります：
   - `Wonder Rinko`
   - `WonderLinko`
   - `WonderLinkoDesktop`
   - または `Python` など（環境によって異なります）
4. 該当しそうなキーを **右クリック → 削除** する（不確かな場合は削除せず、方法Bのスクリプトを利用してください）
5. レジストリエディターを閉じ、**Wonder Linko を終了してから再起動**する
6. トレイメニューから **「テストお知らせ（付箋ボードURL付き）」** を実行し、通知が表示されるか確認する

### 方法B: PowerShell で通知設定をリセットする

**`通知設定をリセットする.ps1`** を用意しています。**Wonder Linko を終了した状態で**、PowerShell で次を実行してください。

- **MSI でインストールした場合**: インストール先フォルダ（WonderLinko.exe があるフォルダ）の `docs` サブフォルダにスクリプトがあります。
- **開発環境**: プロジェクトの `02_3_WL_Desktop_app\docs` フォルダにあります。

```powershell
# 例: インストール先が C:\Users\<ユーザー名>\AppData\Local\WonderLink\WonderLinko の場合
cd "$env:LOCALAPPDATA\WonderLink\WonderLinko\docs"
.\通知設定をリセットする.ps1
```

実行後、Wonder Linko を起動し、「テストお知らせ」で通知を試してください。

※ レジストリを変更します。心配な場合は先に方法Aで該当キーを確認してからにしてください。

---

## レジストリ削除でも改善しない場合（アプリの更新で通知IDを変える）

上記のレジストリ削除を試しても通知が復活しない場合、**アプリ側で通知に使う「アプリID」を変更**したバージョンに更新することで改善することがあります。Windows はアプリIDごとに通知のオン/オフを覚えているため、**新しいIDを使うと「別アプリ」として扱われ、通知が再有効化**されます。

- **対応済み**: 新版の Wonder Linko では、通知用のアプリID を **`WonderLinko.Desktop`** に変更しています。
- **手順**: 最新の MSI で再インストール（または上書きインストール）し、アプリを起動して「テストお知らせ」を実行してみてください。通知が表示されれば、設定の通知一覧に「WonderLinko.Desktop」等が現れることがあります。
- 今後、同じ事象になった場合は再度アプリIDを変更した版を配布する対応が可能です。

---

## なぜアンインストールでは直らないか

Windows は「どのアプリの通知を表示するか」を **アプリごとに** 記憶しています。この設定は **アプリのインストールフォルダとは別**（レジストリや Windows の内部設定）に保存されるため、アプリをアンインストールしてもリセットされません。再インストールすると同じアプリとして扱われ、**オフのまま**の設定が引き継がれます。

そのため、通知を再度使うには **Windows の「設定」で該当アプリの通知をオンに戻す**必要があります。
