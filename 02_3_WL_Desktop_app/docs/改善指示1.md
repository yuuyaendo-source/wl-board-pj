# 要件: 常駐型入力ウィンドウ「Rinko Mini-Port」の作成

既存のデスクトップアプリ機能を拡張し、画面右下に常駐する「フローティング入力ウィンドウ」を作成したいです。

## 技術スタック
- 言語: Python
- UIライブラリ: `customtkinter` (モダンなUIのため)
- API通信: `requests`

## UI/UX仕様
1. **ウィンドウの外観:**
   - タイトルバーなし（Frameless）。
   - 常に最前面表示（Always on Top）。
   - 画面の右下（タスクバーの上あたり）に配置。
   - 角丸の「カプセル型」または「検索バー型」のデザイン。

2. **動作:**
   - **ホットキー:** `Ctrl + Shift + Space` を押すとウィンドウにフォーカスが当たり、即座に入力可能になる。
   - **入力:** テキストを入力してEnterキーを押すと送信。
   - **送信後:** - 入力欄をクリア。
     - API (`POST /api/sticky_notes`) にデータを送信。
     - 送信成功時、一瞬「Checkマーク」などを表示してフィードバックを行う。

3. **API連携:**
   - 接続先: `http://localhost:8000/api/sticky_notes` (configから読めるように)
   - Payload: `{"content": "入力テキスト", "board_type": "MAIN"}`
   - ※AIが自動仕分けするので、board_typeはMAIN固定でOK。

この仕様で、`mini_port.py` というファイル名で実装コードを書いてください。
