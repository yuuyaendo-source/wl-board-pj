# wl-sticky-note デプロイ手順（正規版）

本ドキュメントは **wl-sticky-note（付箋ボード）** の正規版をサーバにデプロイする手順です。

- **サーバ**: IP `172.16.1.81` / ドメイン `wl-sticky-note.local`
- **リポジトリ**: wlinko-pj（02_1_sticky-note をその中から取得）
- **clone 対象**: 02_1_sticky-note のみ（sparse-checkout 使用）

**付箋ボードと Board System をまとめて本番デプロイする場合**は、リポジトリルートの **docs/本番デプロイ手順.md** を参照してください。

---

## 1. 前提条件

- Ubuntu Server（20.04 LTS 以降推奨）
- SSH と sudo が使えること
- Git 2.25 以上（sparse-checkout 用）

---

## 2. サーバに SSH 接続

```bash
ssh user@172.16.1.81
# または
ssh user@wl-sticky-note.local
```

---

## 3. 02_1_sticky-note を clone する

wlinko-pj リポジトリ全体ではなく、**02_1_sticky-note のみ**をワーキングツリーに取り出します。

```bash
# ディレクトリ作成
sudo mkdir -p /var/www/wl-sticky-note
sudo chown $USER:$USER /var/www/wl-sticky-note
cd /var/www/wl-sticky-note

# wlinko-pj を sparse で clone
# ※ YOUR_ORG を実際の GitHub ユーザー/組織名に置き換えてください
git clone --filter=blob:none --sparse https://github.com/YOUR_ORG/wlinko-pj.git .

# 02_1_sticky-note だけをチェックアウト
git sparse-checkout set 02_1_sticky-note
git checkout
```

この結果、`/var/www/wl-sticky-note/02_1_sticky-note/` の下にファイルが並びます（README.md, docs/, src/ など）。

---

## 4. デプロイの実行

アプリ本体は `02_1_sticky-note/src` にあります。ここで `deploy.sh` を実行します。

```bash
cd /var/www/wl-sticky-note/02_1_sticky-note/src

# 実行権限を付与
chmod +x deploy.sh

# デプロイ実行（Node.js / PM2 / Nginx のインストール〜起動まで行う）
./deploy.sh
```

`deploy.sh` が行うこと:

- システム更新・curl / git / nginx のインストール
- Node.js 20.x LTS のインストール（未導入時）
- PM2 のインストール（未導入時）
- `npm install` / `npm run build`
- PM2 で `wl-sticky-note` として起動（ポート 3000）
- Nginx の設定（`wl-sticky-note.local` / `172.16.1.81` → 3000）
- ファイアウォールで 80 番を許可（ufw 使用時）

## 5.5 AI-Board 連携（付箋追加を AI-Board に通知）

付箋を追加したときに AI-Board に表示・リン子が反応するには、**付箋ボードが動いているサーバ**の `src/.env` に以下を設定し、PM2 を再起動してください。

1. `src` ディレクトリに移動（`02_1_sticky-note/src` または `releases/02_1_sticky-note/src`）。
2. `.env` がなければ `cp .env.production.example .env` で作成し、次の2行を追加または編集する。
   - `AI_BOARD_URL=https://172.16.1.251:5000`（AI-Board の実際の URL に合わせる）
   - `AI_BOARD_INSECURE_SSL=1`
3. 依存関係の更新と再起動:
   ```bash
   npm install
   pm2 restart wl-sticky-note --update-env
   ```

- **AI_BOARD_URL**: AI-Board が動いている URL。HTTPS の場合は `https://172.16.1.251:5000` のように指定。
- **AI_BOARD_INSECURE_SSL=1**: AI-Board が自己証明書の場合は必須（付けないと「Failed to notify AI-Board: fetch failed」になる）。

再起動後、`pm2 logs wl-sticky-note` で `AI-Board URL: https://172.16.1.251:5000` と出ていれば .env が読まれています。

## 6. 今後の更新（コードの反映）

修正を反映するときは、同じディレクトリで pull し、再度ビルド・再起動します。

```bash
cd /var/www/wl-sticky-note
git pull

cd 02_1_sticky-note/src
# pull 後は .next を消してからビルド（Next.js のエラーを防ぐ）
rm -rf .next
npm install
npm run build
pm2 restart wl-sticky-note --update-env
```

- **`rm -rf .next`**: 古いビルドキャッシュを削除します。pull 後に「This is a bug in Next.js」などが出る場合は必須です。
- sparse-checkout の設定はそのままなので、`git pull` で 02_1_sticky-note 以下だけが更新されます。

## 8. トラブルシューティング

### pull 後に「This is a bug in Next.js」が出る

古い `.next` ビルドが残っていると発生します。**クリーンビルド**してください。

```bash
cd /var/www/wl-sticky-note/02_1_sticky-note/src
# または releases の場合: cd /var/www/wl-sticky-note/releases/02_1_sticky-note/src

rm -rf .next
npm install
npm run build
pm2 restart wl-sticky-note --update-env
```

## 9. 補足

- **clone するのは 02_1_sticky-note のみ**: `git sparse-checkout set 02_1_sticky-note` により、wlinko-pj の他のディレクトリはワーキングツリーに含まれません。
- **本番 API**: 付箋ボードのサマリーは `GET /api/boards/wl/summary`、付箋追加は `POST /api/sticky_notes`。Desktop アプリ・AI-Board の連携は `docs/本番連携の整理.md` を参照。
