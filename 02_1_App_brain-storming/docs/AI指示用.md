# プロンプト構成案
あなたは優秀なウェブエンジニアです。
以下の【要件定義】をもとに、モダンで美しいアプリを作成してください。

## 【要件定義】
# アプリ設計書：[ブレインストーミングアプリ]

## 1. 概要（コンセプト）
- ターゲット： [社員]
- 現状の課題： [ブレインストーミングをするための環境がない]
- 解決策　　： [ブレインストーミングが手軽にできるアプリを作成する]

## 2. 必要な機能（ロジック）
- ブレインストーミング開催ごとにボードが作成でき、保存ができるようにする。
- 複数メンバーが同じ画面上で同時に操作ができるようにする。
- 参加メンバーそれぞれが付箋を作れるようにする。
- 誰が書いた付箋かわかるようにするようにする。
- 付箋の9色で自由に変えられるようにする。
- 付箋は画面上のフリースペース内を自由に移動できるようにする。
- 付箋と付箋を線でつなぐことができるようにする。
- アプリはUbuntuサーバにデプロイし、ブラウザから利用できるようにする。

### 付箋に入力するもの
- [ ] [コメント]

### 処理のルール（ここが重要！）
- [x] [ブラウザでアクセスできるようにする。]
- [x] [新規作成ボタンで新しくボードが作成できる]
- [x] [再開ボタンで以前のボードが開ける]
- [x] [ボードごとにURLのパスを生成]
- [x] [参加者の名前を入力できる]
- [x] [参加者は付箋にコメントを書ける]
- [x] [付箋をクリックすることで移動ができる]
- [x] [ボードは拡大縮小できる]
- [x] [保存ボタンでボードを保存できる]

## 3. 画面イメージ
**どんな見た目にしたいですか？（言葉または手書き写真を貼り付け）**
- 全体的にシンプルにする。（スマホで押しやすく）
- 全体の色合いは「明るい緑」を基調にする
- フリースペースボードは白にする

## 【制約事項】
- 環境変数は専用のファイルを作成してください。
- エラーが出ても自己修復してください。
